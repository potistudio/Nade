# Examples

`examples/` は以下の3カテゴリで整理しています。

## 1. Current (Iced 0.14)

- `custom_slider`
- `gizmos`

## 2. Current (egui/eframe)

- `node_playground_egui`
- `playground_font`
- `timeline` (`timeline_demo_egui`)

## 3. Legacy (Iced 0.13)

- `custom_slider_iced`
- `node_demo`
- `panel_system_iced`
- `preview_system_iced`
- `timeline_iced` (`timeline_demo_iced`)

`Legacy` は旧APIの挙動検証用サンプルです。新規追加・更新は `Current` 側を優先してください。

## Run

- 例: `cargo run -p gizmos`
- 例: `cargo run -p node_playground_egui`
- 例: `cargo run -p timeline_demo_iced`
